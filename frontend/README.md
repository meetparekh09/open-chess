# Open Chess frontend

React + TypeScript + Vite UI for Open Chess. See the [main README](../README.md) for setup;
from the repository root, `make dev` runs it together with the API.

On its own: `npm install`, then `npm run dev` (expects the API on port 8000; Vite proxies
`/api` to it). Run `npm run lint` and `npm run build` before sending changes.
